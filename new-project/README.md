# PNM Sea Foods

A simple online seafood marketplace starter project.

## Open the project

Open `index.html` in a browser.

## Features

- Fresh seafood product cards
- Category filter
- Add-to-order cart
- Customer order form
- Local image assets

## Customize

- Change business name and contact details in `index.html`
- Edit product names, prices, and images in `script.js`
- Adjust colors and layout in `styles.css`
